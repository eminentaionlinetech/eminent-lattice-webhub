# Eminent Lattice Webhub

Create a premium, ultra-modern website marketplace hub named "Eminent Lattice Web-Hub". 

Design Guidelines:
- Use a high-end tech aesthetic featuring dark mode (deep grays/blacks) with vibrant blue/cyan accents.
- Layout must be extremely clean, modern, and highly responsive for both mobile and desktop screens.

Page Structure:
1. Header Navbar: Include the name "Eminent Lattice Web-Hub" on the left, and simple navigation links (Explore, How It Works, Contact) on the right.
2. Hero Section: Display a large bold title "Eminent Lattice Web-Hub" with a subtitle that reads: "Instant Turnkey Websites and Digital Assets for Nigerian Businesses. Pay securely via Korapay and receive your admin login credentials instantly."
3. Product Grid Section: Below the hero, build a clean grid layout showcasing empty placeholder product cards so we can fill them with specific website models next. Each card should have space for a preview image container, title, category badge, feature list, bold price tag in Naira (₦), and an action button.
